# EXP-005 protocol: second test on a real network (independent cascade)

**Status: FROZEN, version 1.0 (owner-approved 2026-11-24), not yet run. Secondary confirmatory experiment (the second test of `research/protocol.md` section 11.5).**
Version 1.0, 2026-11-24. Protocol hash: in `research/freeze.json`. Written before the calibration fit; the fitted values were then inserted into items 8 and 11 and into the config.

1. **Precise question.** On one real social network, at matched transmission probability, does the expected IC final cascade fraction differ from that of (a) random graphs with the same node and edge counts and (b) degree-preserving randomisations of the same network?
2. **Mechanism.** Under the locally tree-like approximation, IC final size depends on the degree moments (bond percolation). Real social networks also carry clustering, communities and degree correlations, which the tree-like approximation ignores. Contrast (a) measures the combined effect of degree heterogeneity and other structure; contrast (b) holds the degree sequence fixed and isolates the other structure.
3. **Rationale.** Complements the synthetic EXP-002 with one real topology, as approved by the owner on 2026-11-24 (real data only if a licence recheck is clean; recheck in `research/protocol.md` section 11.5).
4. **Data.** B. F. Maier's anonymized Facebook friendship network (fall 2014): 362 nodes, 1988 edges, pseudonymous integer ids, the account owner removed. Source: GitHub `benmaier/BFMaierFBnetwork`, commit `d1446af55483c98d93f72015b6238200e1a30575`, MIT License; listed in Netzschleuder as `facebook_friends`. Downloaded by `scripts/download_data.py`, ingested by `scripts/ingest_data.py` (`viral.realdata.ingest_gml`). Raw and processed files are git-ignored; SHA-256 values are in `data/manifest.json`. Cite Maier and Brockmann, Phys. Rev. E 96, 042307 (2017).
5. **Hypotheses.** For each calibrated `p_j` and each null `N` in {`real_er`, `real_dpr`}: H0 `Delta_N(p_j) = 0`; H1 `Delta_N(p_j) != 0` (nondirectional).
6. **Estimand.** `Delta_N(p_j) = E_r[ Sbar_{real,r}(p_j) - Sbar_{N,r}(p_j) ]`, where `Sbar_{X,r}(p)` is the mean final cascade fraction over 200 cascades of batch `r` on graph `X_r` (for the real arm, the same network for every `r`).
7. **Experimental unit.** The matched set `r`: one null graph of each kind and one cascade batch on the real network, with shared random streams. Inference is conditional on the single real network.
8. **Independent variables.** Graph (real, `real_er`, `real_dpr`); `p` in {0.005806, 0.014516, 0.029031, 0.043547, 0.058062, 0.087093, 0.145155} = `round(c p_c(G_real), 6)` with `c` in {0.12, 0.30, 0.60, 0.90, 1.20, 1.80, 3.00} and fitted `p_c(G_real) = 0.0483851339839852` (calibration method in `research/protocol.md` section 11.5, fit in `data/real_network_calibration.json`). One uniformly random seed. **Dependent variables.** `S` (primary for this experiment), `D`, `T50`, Gini, large-cascade share (secondary, unadjusted).
9. **Treatment and control.** Treatment: the real network. Controls: `real_er` = G(n = 362, M = 1988), seeded; `real_dpr` = the real network after `10 M = 19,880` seeded double-edge swaps.
10. **Baseline.** Each null is the baseline of its own contrast.
11. **Seed plan.** Master seed 20261128; graph streams keyed by (topology, replicate); cascade streams keyed by (replicate, setting), shared across the three arms. `R = 120`, `C = 200`.
12. **Sample-size rationale.** `R = 120` as in EXP-002, so that both experiments have the same Holm family size (14) and the same replicate count. No pilot was run on the real network.
13. **Compute budget.** 3 x 7 x 120 x 200 = 504,000 cascades on 362 nodes plus 120 sets of 19,880 swaps (about 0.1 s each, measured once for graph construction only); at most 30 minutes.
14. **Metric formulas and units.** As EXP-002 item 14, with `N = 362`.
15. **Uncertainty method.** Paired cluster bootstrap over `r`, `B = 10000`, one Holm family of 14 contrasts (2 nulls x 7 probabilities), Holm-adjusted intervals as in `research/protocol.md` section 11.3, bootstrap stream `SeedSequence(20261128, spawn_key=(2,))`.
16. **Exclusion and stopping rules.** Ingestion exclusions are fixed in `research/protocol.md` section 11.5 (the recorded counts were all 0: no missing, unknown, self-loop or duplicate edge). No cascade is excluded. Isolated nodes (14) and small components are kept; a random seed on an isolated node gives `S = 1/362`. Fixed matrix, no optional stopping.
17. **Anticipated failure modes.** The swap routine failing to reach `10 M` swaps within its try budget (networkx raises; the run stops and is reported). Near-saturation cells with almost no variance (kept, reported).
18. **Sensitivity tests.** None beyond the two nulls. One network only: no generalisation to other real networks.
19. **What would contradict H1.** Holm does not reject for a contrast. Equivalence for `(N, p_j)` is claimed only if its interval lies inside `[-0.02, 0.02]`.
20. **Reproducibility commands.** `.venv/bin/python scripts/download_data.py`; `.venv/bin/python scripts/ingest_data.py`; `.venv/bin/python scripts/fit_calibration.py`; `.venv/bin/viral run --config experiments/EXP-005/config.json`. Claims boundary: a simulation on one anonymized friendship network; no statement about Facebook, its algorithms or any real platform.
