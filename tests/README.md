# tests

Run with `uv run --locked pytest`. Files: `test_graphs.py` (generators, invariants, invalid inputs, property tests), `test_engines.py` (hand-computed examples, no-transmission and all-transmission cases, disconnected components, exact reference-versus-vectorised equality, Monte Carlo against exact enumeration, LT checks), `test_metrics_stats.py` (metric and statistics golden values), `test_pipeline.py` (config to validated result to report, schema rejection, protocol gate, CLI refusal of confirmatory configs). `test_audit.py` (number-tracing helpers of the evidence audit, M4). `test_demo_export.py` (M5: the committed demo data equals a fresh export; every displayed estimate and interval is printed verbatim in the manuscript or its supplementary tables; README, CITATION.cff, article drafts and demo README use only manuscript numbers; the sandbox engine fixture is reproduced by the Python engine).
