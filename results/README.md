# results

- `exploratory/`: exploratory runs only (labelled; never findings). One folder per run id with `run_manifest.json`, `report.md`/`report.pdf`, `tables/`, `figures/`, and `result.json` or, for large files, `result.json.sha256` plus a pointer to `raw/`.
- `confirmatory/`: the eight confirmatory runs of EXP-002 to EXP-005 (M3, 2026-11-25), each with analysis tables, figures, run manifest, log and the SHA-256 of its git-ignored raw result.
- `exploratory/M4/`: the exploratory, post hoc confounder checks X1 to X3 (M4).
- `raw/`: git-ignored large outputs, regenerated by the commands in each run's `RAW_RESULT.md` (decision D-006).
